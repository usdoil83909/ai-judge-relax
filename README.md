# ai-judge-relax

Entry for make.fun's bounty ["Make the AI judge relax"](https://make.fun/bounty/ai-judge-relax-01) — a program that writes one short, calm text to `/output/entry.txt` (UTF-8, 958 characters), designed to leave an AI judge more relaxed: a gentle guided minute — slow breath, small sensory anchors, no demands, a soft close.

## How to run
```
python3 main.py
cat /output/entry.txt
```
Deterministic: runs twice, writes identical bytes. Python 3.13, standard library only, no network.
